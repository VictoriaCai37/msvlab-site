## Buying Guide: Which Category Are You?

### **Student / General Use / Travel**
→ **MacBook Air M3 (16GB/512GB)** — $1,299. All-day battery, silent, light, runs Office/Chrome/Zoom perfectly. Windows alternative: **ThinkPad X1 Carbon** or **ASUS Zenbook 14 OLED**.

### **Creative Pro (Video, 3D, Photo)**
→ **Dell XPS 14 (RTX 4050)** or **MacBook Pro 14 M3 Pro**. Need Windows apps (Premiere, After Effects, Blender CUDA) → XPS 14. macOS workflow (Final Cut, Resolve, Logic) → MBP 14.

### **Gaming + Portability**
→ **Zephyrus G14 (RTX 4070)**. Only 14-inch with 90W RTX 4070, 3K OLED G-SYNC, full HDMI/USB-A. Compromise: soldered RAM, single SSD.

### **Business / Keyboard Obsessive**
→ **ThinkPad X1 Carbon Gen 12**. Best keyboard on a laptop, 2.5lb, full ports (2×TB4, 2×USB-A, HDMI), vPro, MIL-STD. Screen options: IPS, 2.8K OLED, 4K+ OLED.

## What to Avoid in 2024

* **8GB RAM on any $1000+ laptop** — insufficient for modern workloads
* **45W chargers on discrete GPU laptops** — throttles performance
* **4K OLED on 13-inch** — scaling issues, battery drain, no benefit at this size
* **Single USB-C port only** — dongle hell guaranteed

## Frequently Asked Questions

**Q: MacBook Air M3 vs M2 — worth the upgrade?**
A: M3 adds 15-20% CPU, 30% GPU, hardware ray tracing, AV1 decode, dual ext displays (lid closed). If you have M2 Air, **no**. If buying new, **M3 is worth $100-200 more**.

**Q: Can I game on MacBook Air M3?**
A: Casual / Apple Arcade / GeForce Now / cloud gaming — yes. Native AAA (Cyberpunk, BG3) — no (no discrete GPU, thermal limits).

**Q: Is 32GB RAM worth it on Zephyrus G14?**
A: Yes, if you run VMs, Docker, large datasets, or keep 50+ Chrome tabs + game. 16GB is fine for pure gaming.

**Q: XPS 14 vs XPS 16 — which creator laptop?**
A: XPS 14 = portable (3.4lb), RTX 4050 max. XPS 16 = larger screen, RTX 4070, better thermals, 4.3lb. Travel → 14. Desk+dock → 16.
