# Ms V Lab - Static Review Site

> **Stack**: Astro 4 + Tailwind CSS + Pagefind Search + Decap CMS
> **Deploy**: Cloudflare Pages (static upload or Git integration)
> **Domain**: msvlab.site

---

## Quick Start (No Code Required)

### Option A: Double-Click Scripts (Windows)
1. **Unzip** the project folder
2. **Double-click `preview.bat`** - browser opens `http://localhost:4321`
3. Browse, test, click **Logo A/B/C** in header to pick your favorite
4. **Double-click `build.bat`** - generates `dist/` folder
5. **Drag `dist/` folder** to Cloudflare Pages "Upload assets"
6. Done! Site live at `https://msvlab.site`

### Option B: Command Line (Mac/Linux/WSL)
```bash
cd msvlab-site
npm install          # first time only
npm run dev          # preview at localhost:4321
npm run build        # generates dist/
```

## Adding New Reviews (No Code!)

### Method 1: Local CMS (Recommended)
1. Run `npm run dev` or double-click `preview.bat`
2. Open `http://localhost:4321/admin`
3. Click **"New Review"** / **"New Best Products"** / **"New Deal"**
4. Fill the form:
   - **Title** (120 chars max)
   - **Excerpt** (200 chars max)
   - **Hero Image** + **3+ Gallery Images** (drag & drop)
   - **Category**: Smart Home / Computing / Audio
   - **Tags**, **Publish Date**, **Read Time** (e.g., "12 min read")
   - **Rating** (1-5)
   - **Pros** (min 3), **Cons** (min 2)
   - **Who Should Buy** (min 3)
   - **Verdict** (your conclusion)
   - **Specs** (optional key-value pairs)
   - **Price** + **Affiliate URL** (optional)
5. Click **"Publish"** - saves as `.mdx` file in `src/content/`
6. Run `build.bat` - upload new `dist/` to Cloudflare

### Method 2: Edit Markdown Directly
1. Copy any file in `src/content/reviews/` (e.g., `roborock-s8-maxv-ultra.mdx`)
2. Rename to `your-product-name.mdx`
3. Edit frontmatter (the `---` block at top) with your data
4. Write content below the frontmatter in Markdown
5. Run `build.bat` - deploy

## Deployment

### Cloudflare Pages (Drag & Drop)
1. Run `build.bat` - creates `dist/`
2. Cloudflare Dashboard - Pages - **Upload assets**
3. Drag **entire `dist` folder** (not contents)
4. Add custom domain `msvlab.site` in Pages - Custom domains

### Cloudflare Pages (Git Integration) - Recommended for updates
1. Push this repo to GitHub
2. Cloudflare Pages - Connect to Git - select repo
3. Build: `npm run build` | Output: `dist`
4. Every `git push` - auto-deploy

## Content Guidelines (For Affiliate Approval)

### Review Requirements
- Title 120 chars max
- Excerpt 200 chars max
- Hero image + 3+ gallery images
- Original testing text (not copied)
- Pros (3+), Cons (2+), Who Should Buy (3+), Verdict
- Affiliate disclosure banner (auto-injected)
- Specs table (where applicable)

### Best Products Guides
- 3+ products with rank, image, rating, pros/cons, best-for, price, affiliate link

### Deals
- Original price, sale price, discount %, merchant, affiliate link, expiry date

## Troubleshooting

| Issue | Fix |
|---|---|
| `preview.bat` fails | Run `npm install` manually in folder |
| Images not loading | Check `heroImage` path starts with `/images/` |
| Search not working | Run `npm run pagefind` after build |
| CMS won't load | Ensure `public/admin/config.yml` exists |
| Deploy shows old content | Clear Cloudflare cache (Caching - Purge All) |
| Fonts look wrong | Ensure `npm run build` (not just dev) |
